# Miloš Komljen Portfolio Site

Ovo je statički lični portfolio spreman za GitHub Pages.

## Šta je unutra

- `index.html` - glavna stranica
- `styles.css` - izgled sajta
- `script.js` - EN/SR prebacivanje i automatski CV download po jeziku
- `assets/` - hero slika i CV fajlovi na engleskom i srpskom

## Najlakše postavljanje na GitHub Pages

1. Otvori GitHub i napravi novi public repository.
2. Ako želiš glavni portfolio URL, nazovi repository tačno:
   `miskebg.github.io`
3. Ako želiš projektni URL, može i naziv:
   `milos-komljen`
4. Uploaduj sve fajlove iz ovog foldera u root repository-ja.
5. Otvori **Settings > Pages**.
6. Kod **Source** izaberi **Deploy from a branch**.
7. Izaberi branch `main` i folder `/root`, pa klikni **Save**.

Ako repository nazoveš `miskebg.github.io`, sajt će biti ovde:

`https://miskebg.github.io/`

Ako repository nazoveš `milos-komljen`, sajt će biti ovde:

`https://miskebg.github.io/milos-komljen/`

GitHub-u obično treba minut ili dva da prvi put objavi stranicu.
